---

### Fixed

- `upgrade` no longer re-adds files for optional features (Docker, Kubernetes, Prisma Studio) that were declined at scaffold time — the manifest now records the chosen features (new `version` and `features` fields) and upgrade skips files for any opted-out feature; projects scaffolded before this change have their features inferred from disk and the manifest is self-healed on the next upgrade
- Scaffolding now removes the repo-only `CONTRIBUTING.md` and `SECURITY.md` guides instead of shipping them into generated projects, and `upgrade` sources its skip list from the canonical internal-files list so the two can no longer drift
